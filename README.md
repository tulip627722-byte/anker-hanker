# 寻忆｜一颗珠珠，接住突然想起的话

寻忆是一款面向老人及其家庭的声音记忆产品。老人通过手机挂绳上的声音记忆珠完成低门槛录音；回到手机后，App 将零散原声整理为可回听、可补充、可传承的家庭故事。

> 真声是主角，AI 负责整理；自动沉淀不等于自动分享。

## 在线体验

本仓库为无需构建的静态交互原型。部署 GitHub Pages 后，可直接从仓库首页进入 Demo。

本地预览：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/寻忆-demo/
```

## 核心体验

### 1. 珠珠带回一段声音

录音由硬件珠珠的实体按键触发。App 不直接收音，只呈现珠珠连接状态、回传的原声和地点线索。

### 2. 故事逐步浮现

用户点击“收下这段声音”后，系统依次识别地点、人物和相关旧片段，再把新原声与已有故事关联。过程保留原声，不用 AI 补写不确定信息。

### 3. 回到真实原声

故事页支持播放原声、查看整理后的叙事，以及展开“这段故事从哪里来”，追溯每条信息对应的讲述来源。

### 4. 家人一起听

共忆模式先让家人听老人说完；谈话停顿后，系统才递出一条可忽略、可切换的开放式追问。

### 5. 声音走过的地方

足迹页以地点作为记忆线索，连接同一地点发生过的多段故事。地点能力可以关闭，不保存完整行动轨迹。

## Demo 路径

```text
珠珠完成录音
    ↓
App 收到一段新声音
    ↓
地点、人物与旧片段逐步浮现
    ↓
进入故事页回听原声与查看来源
    ↓
家人进入“一起听”，继续讲述
```

建议体验顺序：

1. 点击“收下这段声音”。
2. 等待三阶段整理动效完成。
3. 点击“听完整故事”。
4. 播放原声并展开故事来源。
5. 进入“今晚一起听”，切换不同追问。
6. 在“足迹”中切换旧电影院与老院子。
7. 点击右上角头像查看珠珠状态与隐私偏好。

## 产品边界

- 寻忆不是记忆测试、医疗诊断或治疗设备。
- 原声始终保留，AI 摘要不能覆盖原始表达。
- 自动沉淀仅发生在个人记忆空间；家庭分享需要用户主动选择。
- 对无法确认的年份、人物关系或事实，产品明确显示“不确定”，不让 AI 猜测。
- 用户可以关闭地点线索、撤回家庭分享，或彻底删除原声及衍生内容。

## 技术说明

- 原生 HTML、CSS、JavaScript，无构建依赖。
- Demo 使用脚本化数据展示产品闭环，不代表已经接入量产硬件或线上 AI 模型。
- 页面采用移动端优先设计，桌面端以手机画布形式展示。

## 当前状态

这是黑客松预赛交互原型，重点验证：

- 硬件录音与 App 整理的职责边界是否清晰。
- AI 的介入是否自然、不打断老人讲述。
- 家人是否愿意围绕真实原声继续听、继续问。
- 自动长期记忆与用户控制能否同时成立。
