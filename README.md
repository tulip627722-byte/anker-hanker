# 寻忆｜一颗珠珠，接住突然想起的话

寻忆是一款面向老人及其家庭的声音记忆产品。老人通过手机挂绳上的声音记忆珠完成低门槛录音；回到手机后，App 将零散原声整理为可回听、可补充、可传承的家庭故事。

> 真声是主角，AI 负责整理；自动沉淀不等于自动分享。

![寻忆 Demo 暖色首屏](./assets/demo-cover.png)

## 在线体验

本仓库为无需构建的静态交互原型。部署 GitHub Pages 后，可直接从仓库首页进入 Demo。

## 核心体验

### 1. 珠珠带回一段声音

录音由硬件珠珠的实体按键触发。App 不直接收音，只呈现珠珠连接状态、回传的原声和地点线索。

### 2. 新声音自动找回旧故事

用户点击“让 AI 找回与它有关的记忆”后，系统依次展示地点、人物、主题和候选记忆的匹配过程。新原声不是生成一份孤立摘要，而是让旧故事从 1 段原声生长为 2 段。

### 3. 回到真实原声

故事页支持播放原声、查看整理后的叙事，以及展开“这段故事从哪里来”，追溯每条信息对应的讲述来源。

### 4. 家人一起听

共忆模式先让家人听老人说完；谈话停顿后，系统才递出一条可忽略、可切换的开放式追问。

### 5. 声音走过的地方

足迹页以地点作为记忆线索，连接同一地点发生过的多段故事。地点能力可以关闭，不保存完整行动轨迹。

## Demo 路径

```text
珠珠完成录音
    ↓
App 收到一段新声音
    ↓
地点、人物与旧片段逐步浮现
    ↓
进入故事页回听原声与查看来源
    ↓
家人进入“一起听”，继续讲述
```

建议体验顺序：

1. 点击“让 AI 找回与它有关的记忆”。
2. 观察真声、地点、人物与候选记忆的匹配动效。
3. 在“记忆 v2”查看原声从 1 段生长为 2 段。
4. 点击“查看记忆如何长出来”，播放原声并检查来源证据。
5. 进入“家庭共忆”，看 AI 如何先等她说完，再递一句非诱导问题。
6. 在“足迹”中切换旧电影院与老院子。
7. 点击右上角头像查看珠珠状态与隐私偏好。

## 产品边界

- 寻忆不是记忆测试、医疗诊断或治疗设备。
- 原声始终保留，AI 摘要不能覆盖原始表达。
- 自动沉淀仅发生在个人记忆空间；家庭分享需要用户主动选择。
- 对无法确认的年份、人物关系或事实，产品明确显示“不确定”，不让 AI 猜测。
- 用户可以关闭地点线索、撤回家庭分享，或彻底删除原声及衍生内容。

## 技术说明

- 原生 HTML、CSS、JavaScript，无构建依赖。
- Demo 不只播放预设页面：前端会用人物、地点、主题和关键词计算候选记忆得分，再把匹配结果写入本地长期状态。
- `localStorage` 保存“是否已沉淀、匹配记忆、原声数量”，刷新后仍可回放。
- 当前规则引擎是产品逻辑演示，不代表已接入量产硬件、ASR 或线上大模型。
- 页面采用移动端优先设计，桌面端以手机画布形式展示。

## 当前状态

这是黑客松预赛交互原型，重点验证：

- 硬件录音与 App 整理的职责边界是否清晰。
- AI 的介入是否自然、不打断老人讲述。
- 家人是否愿意围绕真实原声继续听、继续问。
- 自动长期记忆与用户控制能否同时成立。
